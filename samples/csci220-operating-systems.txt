Course description
This course explains how an operating system manages a computer: processes, scheduling, memory, files and concurrency.

Topics
1. Processes and threads: what a process is, process states, context switching, threads vs processes.
2. CPU scheduling: first-come-first-served, shortest job first, round robin, priority scheduling.
3. Synchronization: race conditions, locks, semaphores, deadlock.
4. Memory management: paging, virtual memory, page replacement.
5. File systems: files and directories, allocation methods, journaling.
Prerequisites for this course: you should understand recursion and linked lists from CSCI 201.
